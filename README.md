# ZETRIX Metal Industries

Bilingual (English / Arabic) company website for **ZETRIX Metal Industries** — steel structures, cable trays, prefabricated systems, galvanizing, laser cutting and aluminum works, Madinah, Saudi Arabia.

Built with Next.js (App Router), TypeScript and Tailwind CSS. Content comes from the company profile.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 — it redirects to `/en`. The Arabic site (RTL) is at `/ar`.

## Edit content

All text for both languages lives in `lib/content.ts`. Images are in `public/images`.
